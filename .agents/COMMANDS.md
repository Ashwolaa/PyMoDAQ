# Commands, agents and scripts

Generated by `python3 .agents/scripts/docs.py --write` from the files themselves (also run by `status.py --write`). Do not edit: change the command, agent or script instead. Start here: `.agents/README.md`.

## Commands (`/optimize-*`, in `.claude/commands/`)

| command | arguments | what it does |
|---|---|---|
| `/optimize-merge` | [scope \| task-id] [--explain] | Validate pushed agent branches (pr-reviewer), open their PRs, merge the low-risk ones into dev_agent |
| `/optimize-plan` | [scope] [--explain] | Advisory board: scan a scope, deliberate, and write a plan of tasks (never edits code) |
| `/optimize-plugins` | discover \| assess <name\|url> [--top N] \| port <name\|url> [--explain] | Plugin compatibility: discover PyMoDAQ plugins (PyPI and users' GitHub repos), assess them, port one to the current PyMoDAQ |
| `/optimize-research` | <topic: one-line question + stopping condition> [--explain] | R&D: research one topic or prototype it on an agent-rd branch (never merges by itself) |
| `/optimize-revert` | <run-id> | Undo an agent run by reverting its merged PRs on dev_agent |
| `/optimize-review` | [--explain] | Independent committee reviews the use of agents and coordinator roles from the numbers |
| `/optimize-run` | [scope \| task-id] [--explain] | Executive: carry out approved tasks of the plan on agent branches within the budget |
| `/optimize-status` | - | Show today's budget use, task queue, blocked items and recent agent PRs |

## Scripts (`.agents/scripts/`, run with `python3` after `[tools].env`)

| script | what it does |
|---|---|
| `budget.py` | Budget gate |
| `ci.py` | CI for agent branches and PRs, with failures compared against upstream/dev |
| `docs.py` | Generate .agents/COMMANDS.md: every command, agent, script and runner, from the files themselves |
| `findings.py` | Findings that do not come from a scan (e.g. CI failures upstream/dev has too). |
| `ledger.py` | Run ledger |
| `merge.py` | /optimize-merge, one candidate at a time. |
| `merge_gate.py` | Decide whether a reviewed agent branch may merge into dev_agent without the human |
| `plan.py` | Set the status of one task in a plan file (the only way runs change a plan) |
| `pr_stats.py` | PR size versus time-to-merge, to set `[limits].pr_max_changed_lines` from data instead of a guess |
| `registry.py` | Branch/PR registry |
| `scan.py` | Deterministic scan of one scope: the only input the advisors get |
| `status.py` | The consortium's state in one page, built from the state files only (never edited by hand) |
| `sync_branches.sh` | Keep `dev` a pure mirror of upstream/dev and merge it into `dev_agent` (merge commit, no history rewrite) |
| `task.py` | One /optimize-run task, step by step. |
| `usage.py` | Measure Claude Code usage from the local session transcripts (no guessing) |

Shared library `agentlib/`: `evidence` What a session really did, read from its transcripts: the proof task.py and merge.py ask for (rules.md 16); `gitx` Running git and other commands from the scripts; `plans` Plan files (`.agents/plans/*.md`): task blocks, their fields and statuses, and the package each task belongs to; `reports` pr-reviewer reports (`.agents/reports/<package>/<date>-pr-review-<task-id>[-r<N>].md`).

## Runner (`.agents/runner/`)

| file | what it does |
|---|---|
| `cost.py` | What a cycle step costs in plan quota, measured, so the wheel only starts a step that fits |
| `cycle.sh` | One turn of the wheel: sync, then up to MAX_STEPS steps chosen by `status.py next` (merge pending branches > run the next approved task > plan the next scope > weekly review > idle), each a fresh head |
| `step.py` | Run one headless Claude Code step and stop it at its first final result |
